W-G-O NetNavi is a gamified Android app that turns everyday activities into XP-earning adventures for Wallas and Melynna. This guide walks you through everything a parent or guardian needs to do — from installing the app to logging your child's first mission event — so your family is up and running in just a few minutes.

<Steps>
  <Step title="Build or Install the App">
    W-G-O NetNavi is built with **Kotlin + Jetpack Compose** in Android Studio, so you can either compile it from source or sideload a pre-built APK onto your device.

    Before you begin, confirm your device meets the minimum requirements:
    - **Android version:** 8.0 (API level 26) or higher
    - **Free storage:** ~50 MB

    **To build from source:**
    1. Open the project folder in Android Studio.
    2. Wait for Gradle to finish syncing all dependencies.
    3. Select your target device or emulator from the toolbar, then click **Run ▶**.

    <Note>
      If you received a pre-built APK instead, go to **Android Settings → Security** and enable **Install from unknown sources**, then tap the APK file to begin installation.
    </Note>
  </Step>

  <Step title="Select a Character">
    Once the app launches, you land on the main screen where both characters are waiting. Tap **Wallas** (blue) or **Melynna** (pink) to enter their personal dashboard.

    Each character's dashboard displays:
    - **XP Total** — the cumulative points earned so far
    - **Level Badge** — the character's current level
    - **Progress Bar** — how close they are to the next level
    - **3D Avatar** — a visual representation of the chosen character
  </Step>

  <Step title="Log Your First XP Event">
    With a character selected, you're ready to record your child's first activity. Tap the **+** button anywhere on the dashboard, or navigate to the **Actions** panel from the bottom navigation bar.

    Follow these steps to log the event:
    1. Browse or search the activity list and select the relevant action — for example, **Lunch** awards **+5 XP**.
    2. Tap **Confirm** to save the entry.
    3. Watch the progress bar update in real time as the XP is added and written to local storage immediately.

    <CodeGroup>
      ```json Quick XP Event
      {
        "character": "wallas",
        "event": "lunch",
        "xp": 5,
        "date": "2026-09-07",
        "note": "Finished all the food!"
      }
      ```
    </CodeGroup>
  </Step>

  <Step title="View Mission History">
    Tap the **History** tab in the bottom navigation bar to review every event that has been logged for the selected character.

    Each entry in the history list shows:
    - The **activity name** and **XP value** awarded
    - A **timestamp** indicating when the event was recorded
    - An optional **image attachment** — for example, a photo of a drawing from Bob's Goods or another activity keepsake
  </Step>

  <Step title="Import an AI Update (Optional)">
    W-G-O NetNavi supports batch data updates through the **AI Updates** tab, letting you apply a full day's worth of events in one go.

    1. Tap the **AI Updates** tab in the bottom navigation bar.
    2. Choose **Import .wgo Package** to load a bundled update file, or **Import JSON** to paste or load raw JSON data.
    3. Review the **diff preview** to confirm exactly what will change.
    4. Tap **Confirm** — your character's data updates instantly.

    <Tip>
      You can ask any AI assistant (such as ChatGPT or Gemini) to generate a complete daily update for your child as a `.wgo` package. Describe the day's activities in plain language and ask it to format the output using the W-G-O NetNavi JSON schema — then import the file directly into the app.
    </Tip>
  </Step>
</Steps>
