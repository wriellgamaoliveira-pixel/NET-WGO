## The Package Files

A daily update `.wgo` archive contains two required files: `manifest.json` and `data.json`. The manifest tells the app what to expect; `data.json` carries the actual event records for both characters.

### manifest.json

The manifest is the first file the app reads. It validates the schema version and checks the `includes` flags before touching anything else.

```json manifest.json
{
  "schema": "wgo-netnavi",
  "version": "1.0",
  "created": "2026-09-07T22:30:00Z",
  "description": "Daily update — 07/09/2026. Wallas and Melynna both completed Bob's Goods! Great day overall.",
  "includes": {
    "data": true,
    "wallasMdl": false,
    "melynnaMdl": false,
    "images": false
  }
}
```

### data.json

The `data.json` file holds the complete event history for both characters. The app appends each `history` entry to the character's existing log in chronological order, then recalculates totals.

## Pack and Load the Package

Once your two files are ready, pack them into a `.wgo` archive and transfer it to the device running NetNavi.

```bash Create the .wgo package
# On Linux/macOS
zip -r daily-2026-09-07.zip manifest.json data.json
mv daily-2026-09-07.zip daily-2026-09-07.wgo
```

After you create the file, open the NetNavi app, navigate to **Guardian Panel → Load Update**, and select `daily-2026-09-07.wgo`. The app validates the manifest, imports the events, and displays each character's new XP total on their profile screen.

<Tip>
  Always place both `manifest.json` and `data.json` in the **root** of the zip archive — not inside a subfolder. If the app reports a schema error on import, run `unzip -l daily-2026-09-07.wgo` to confirm the file paths are flat.
</Tip>
